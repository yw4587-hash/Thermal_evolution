# data/

* `z_0.000.hdf5`: the z = 0 net-cooling table of Wiersma, Schaye & Smith (2009). It is not included in this repo. Download it from the authors' release and place it here, or set `CGM_COOLING_TABLE=/path/to/z_0.000.hdf5`.
* `entropy_kai{1,4,10}_3e16_200.dat`: the Figure 5 grids, written by the notebook. Columns: T [K], n [cm^-3], log10(K_start/K_end).
